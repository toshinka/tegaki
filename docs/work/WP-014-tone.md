## Goal

網点・ひし形・線のトーンを、範囲Layerを壊さずに貼る。UIは**QTPのタブ**（ペン | トーン）、生成は**確定時**。

## 設計判断

| 論点 | 採用 | 理由 |
|---|---|---|
| 生成方式 | 確定生成。確定時のみCanvas2Dでキャンバス寸法のRGBAを描き、通常Raster Layerとして追加（Undo 1回） | ライブのstrokeにCanvas2Dを使わない契約。画素は派生物 |
| 非破壊 | 選択中のLayerへ**クリッピング**したトーンLayerを直上に作る。範囲Layerは触らない。反転クリップに切り替えれば抜きにもなる | 「全面に貼って消す」をやめ、範囲の差し替えだけで形を変えられる |
| 格子 | キャンバス原点基準・角度回転。別Layer/別操作でも網点がそろう | つなぎ目でずれない |
| 濃度 | セル面積に対する塗り面積。0.5まで中心に点、0.5超は塗り+中心を抜く。線は太さ=濃度×間隔 | 点→抜けが連続し、網点が実物のトーンの見た目になる |
| グラデーション | 向き・開始/終了・終濃度。基準矩形=範囲Layerの不透明部の外接矩形（「範囲に合わせる」ON時） | 範囲に合わせたぼかしが一発で出る |
| 保存 | 編集中params / プリセット6枠はlocalStorage。確定Layerは `layerData.tone`（optional・sanitize済み）。画素は派生物 | 保存契約・History・rendererは不変 |
| 上限 | セル数150万を超える設定（細かすぎる間隔×広い範囲）は確定を拒否して通知 | メモリ/時間の暴走防止 |

## ファイル

- `system/tone-geometry.js` — 純幾何（params正規化、濃度場、格子列挙、セル数見積り、sanitize）。
- `system/tone-raster.js` — 確定画素（Canvas2D）。
- `ui/tone-panel.js` — QTPトーンタブ（数値欄はホイール増減/ダブルクリック入力、プレビュー、プリセット、適用/更新/再編集）。
- 配線: `ui/quick-access-popup.js`（長丸タブ・幅拡張・ドラッグ除外）/ `core-engine.js` / `system/project-manager.js` / CSS（`quick-access-popup.css`、共通部品は`panel-layout-popup.css`）。
- 検証: `build/verify-tone.mjs`（harness domain `tone`）。タブ・クリップ・Undo/Redo・更新・保存往復はChromiumで確認済み。

## 操作

- プリセット1〜6: 空=現在値を保存 / 登録済=呼び出し / Shift+クリック=上書き。
- 形（網点/ひし形/線）、間隔、角度、濃度、グラデーション（濃度(終)/向き/開始/終了）、くっきり（二値）、色（既定=ふたば色 `#800000`、`メイン色`で現在色）。
- `適用`=選択Layerにクリップして新規追加（Undo 1回）。`再編集`→`更新`で置換（Undo 1回）。

## 制約・次の候補

- 範囲Layerの形を後から変えても、トーン画素は貼った範囲の外接矩形で生成済み（外へ広げたら`更新`）。
- グラデーションの向きはキャンバス上のハンドルでなく数値指定。
