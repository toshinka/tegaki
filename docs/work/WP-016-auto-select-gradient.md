# WP-016 自動選択 / グラデーション

状態: TECHNICAL COMPLETE / OWNER ACCEPTANCE PENDING。更新日: 2026-10-02。

## Goal

QTPの「図形・範囲ツール」グループ（矩形選択 / 投げ縄塗り）に **自動選択** と **グラデーション** を追加する。Shift+Lの送りにも入る。

## 設計判断

| 論点 | 採用 | 理由 |
|---|---|---|
| 入力経路 | 選択ツール（`PixelSelectionSystem`）のcapture入力・描画エンジン停止・tool切替での解除をそのまま使い、`toolMode`（`rect`/`auto`/`gradient`）で分ける | ペン系パイプライン（brush-core）に新モードを足さない。確定時に画素を一度だけ書く |
| 自動選択 | クリック→種の画素から、許容値内の連続（既定）/全体の領域を**マスク選択**に。対象は選択中Layer（`ALL`で全レイヤー合成を参照）。許容値0〜128 | `system/auto-select.js`（純粋・スキャンライン）。RGBA差の最大値、両方ほぼ透明なら色を無視 |
| マスク選択の効き方 | 描画の制約（矩形内でも領域外は元に戻す）・Delete（領域だけ消す）。**移動/変形/コピーは非対応**（矩形選択で）と通知 | 既存のselectionは矩形が前提。移動・コピーを誤動作させないよう明示的に止めた |
| グラデーション | ドラッグ（始点→終点）。線形/放射、メイン→サブ / メイン→透明。選択（矩形/マスク）があればその中、なければレイヤー全面。通常のRaster画素 + History 1件（Undo/Redo） | `system/gradient-fill.js`（純粋）。透明へ消すとき色にじみが出ない補間 |
| 保存 | 選択は一時状態（Project・Historyに入らない）。オプションはUI設定 `tegaki-area-tools-v1` | 保存契約を変えない |

## 操作

- QTPの図形・範囲グループ（代表タブ→二行目）から自動選択 / グラデーション。`Shift+L`で矩形選択→投げ縄塗り→自動選択→グラデーションの順に送る。
- 自動選択の二行目: `ALL`（全レイヤー参照）/ `隣接`（外すと同じ色を全て）/ 許容値スライダー。
- グラデーションの二行目: `線形` `放射` `→サブ` `→透明`。ドラッグ中は橙の点線ガイド。

## 制約・次の候補

- 自動選択は選択中Layerの座標（layer-local）で領域を求める。`ALL`（全レイヤー参照）はキャンバス座標で求めるため、変形中のLayerとはずれうる。
- マスク選択の移動・コピー・追加/減算（Shift/Alt）・境界のなじませ（ぼかし/拡張縮小）は未対応。
- 自動選択の領域から、トーンのクリップ元となる「領域Layer」を作る導線は今後の候補。
- Owner実機（液タブ）は未確認。
