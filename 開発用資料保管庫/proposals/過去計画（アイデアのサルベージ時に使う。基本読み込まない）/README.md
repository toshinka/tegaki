# 過去計画・原案保管庫

更新日: 2026-07-28

## 目的

このフォルダは、現行proposalの整理で削ぎ落とした詳細、外部AIの原案、レビュー、解決済み調査、整理前スナップショットを保存するための資料庫である。

通常のPhase開始時には読み込まない。現行正本だけでは判断材料が足りない場合、Plan Bへ切り替える場合、過去案を再評価する場合に限定して参照する。

## 現行正本

- 全体索引: `../00_計画索引.md`
- 短中期順序: `../01_短中期ロードマップ.md`
- UI導線: `../14_UIツール導線・Text・階層Motion将来設計.md`
- Rig / Mesh / Perform / Dynamics: `../15_キャラクターRig・Mesh・Perform統合ロードマップ.md`

過去資料と現行正本が衝突する場合、過去資料を直接実装せず、`AGENTS.md`、`TEGAKI.md`、`PROGRESS.md`、現行Phase、実コードを優先する。

## 分類

### `2026-07_AI提案原案/`

BONE、CAF階層Part、Motion Perform、任意Mesh、統合Rig、DynamicsについてのGEMINI原案、Claudeレビュー、改訂版を保存する。

- 15の`（GEMINI提案）`版と`_改訂版`はSHA-256が完全一致していたため、`_改訂版`だけを保存した。
- 16と17は原案と改訂版に内容差があるため両方を保存した。
- 18と19は統合構造とDynamicsの詳細資料として保存した。
- 原案のPhase番号、型名、既存module評価は実コード照合前の仮案である。

### `2026-07-28_整理前現行資料/`

整理前の索引、長大な短中期ロードマップ、研究計画、変形ロードマップを保存する。完了Phaseの細かな記述や、現行正本から外した履歴を探す時に使う。

### `解決済み調査/`

欄外Raster / Resize監査、WARP座標ずれ報告等、修正完了後に現行proposalから外した診断資料を保存する。再発時の比較に使う。

### `外部AI参考資料/`

Callipeg、ToonSquid、Figma Motion、After Effects、AI engine、Animation architecture、知識バンク運用案等の長大な参考資料を保存する。製品仕様は変化し得るため、正式Phaseでは一次情報と現行実装を再確認する。

### フォルダ直下の旧計画

描画、UI、Animation、Storage、AI動画、PEN作業ログの旧総合計画を保持する。実装済み項目と未実装案が混在するため、そのままPhase化しない。

## サルベージ手順

1. 現行proposalで不足している論点を一つに絞る。
2. 対応する分類の原文だけを読む。
3. `rg`で既存file / class / event / schemaを照合する。
4. 現行正本へ「第一候補 / Plan B / 切替条件 / 停止条件」として短く抽出する。
5. 正式な実装範囲は`task-codex/phase*.md`へ切り出す。

過去資料を現行proposal直下へ丸ごと戻さず、必要情報だけを抽出する。
