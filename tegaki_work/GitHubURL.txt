## 0. 現在地（Phase 7i / LUNA引き継ぎ時点）

- Phase 7h Auto Shape FILLはOwner受入でclose済み。
- 現行Phase 7i Auto Shape LINE / RibbonはStage A〜C、SOL review 1〜3=`A`まで完了。
- pure実装は、単一holeなしalpha islandのopen centerline、`left / center / right`三列Ribbon、2〜3 direct-chain BONEのlongitudinal weight、既存inverse-bind LBSによる0° / 45° / 90°品質Gateまで。
- 保存Mesh / Skinの新schema、別Pose正本、WARP共有は追加していない。Model / History / UI / rendererへのLINE接続もまだ未実装。
- 次のStage DはLUNA / MAX限定。既存Modelの明示`auto-shape-line` dispatch、status / duplicate rebase、Setup青RIGの`AUTO LINE`、一操作一History、既存rollback、Browser確認だけを実装する。
- LINE / FILLを自動分類しない。失敗時にFILLへ自動fallbackしない。pure Stage A〜Cの閾値、manual topology / weight、WARP、別LBS evaluatorへ広げない。
- Stage D後のaccept / closeはSOL / XHighで行う。
