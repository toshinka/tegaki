# EasyReforge Manga Prompter (v2.0 メインプロンプト統合版)

EasyReforge（Stable Diffusion WebUI Forge / reForge）専用の、**1ページ漫画制作・複数コマ領域制御拡張機能**です。

---

## 🌟 v2.0 の主な特徴

1. **メインプロンプト欄との完全統合**:
   - WebUI標準のメインプロンプト入力欄に `BREAK` または `[コマ1]` `[コマ2]` と書くだけで各コマに適用されます。
   - **Danbooruタグ補完（Tag Autocomplete）、ワイルドカード、Dynamic Prompts、LoRAセレクターが 100% 完璧に動作します！**
2. **「📝 メインプロンプト欄にテンプレ枠を挿入」ワンクリック機能**:
   - キャンバス上でコマを割ったら、ボタンを押すだけでメインプロンプト欄に `BREAK \n[コマ1] ...` が自動で書き込まれます。
3. **広々としたクリスタ風キャンバス**:
   - スラッシュ分割、境界線連動ドラッグ、矩形ドラッグ作成、コマ結合、Undo/Redo、王道テンプレート（4コマ、3コマ、5コマ、カットイン、6コマ）を搭載。
4. **日本式MANGA読み順（右上始点）自動ソート**:
   - 右上 $\rightarrow$ 左上 $\rightarrow$ 右下 $\rightarrow$ 左下の順で自動的に `[コマ1]`, `[コマ2]` ... がバインドされます。
5. **Forgeネイティブな高精度・爆速アテンション制御**:
   - SDXL / SD1.5 の Cross-Attention に対して各コマの空間マスクを正確に適用。

---

## 📖 使い方

### 1. キャンバスでコマ割りを作る
- テンプレート（4コマ、3コマ等）を選ぶか、「＋ 横スラッシュ」「＋ 縦スラッシュ」「＋ 矩形ドラッグ作成」で好みのコマ割りにします。

### 2. プロンプトを書く
ツールバーの **「📝 メインプロンプト欄にテンプレ枠を挿入」** を押すか、メインプロンプト欄に以下のように記述します：

```text
<lora:...> masterpiece, monochrome manga style,
BREAK
[コマ1] sky, cloud, flying birds
BREAK
[コマ2] 1girl, close up, smiling
BREAK
[コマ3] cat, house, street
```

※ `[コマ1]` などのタグは書かなくても、`BREAK` で区切るだけで上から順にコマ1、コマ2、コマ3に自動割り当てされます。

### 3. 生成（Generate）
「有効化 (Enable)」にチェックを入れて通常通り Generate を押すだけで、各コマに狙った内容が描かれた綺麗な漫画ページが生成されます！
