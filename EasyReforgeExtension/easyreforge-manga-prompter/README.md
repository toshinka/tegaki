# EasyReforge Manga Prompter (漫画コマ割りプロンプター)

EasyReforge（Stable Diffusion WebUI Forge / reForge）専用の、**1ページ漫画制作・複数コマ領域制御拡張機能**です。

---

## 🌟 主な特徴

1. **クリスタ風 スラッシュ分割（スライス）**:
   - キャンバス上のコマを選択して「横分割」「縦分割」を押すだけで、一瞬でコマを割れます。
2. **境界線（ガター）連動ドラッグ**:
   - コマとコマのセパレーターをドラッグすると、隣接するコマが連動して拡大・縮小します。
3. **コマの結合（マージ） ＆ Undo/Redo**:
   - 分割したコマを「結合」で元に戻したり、`Ctrl+Z` / `Ctrl+Y` で直前の操作を取り消し・やり直し可能。
4. **特殊コマ（L字型・入れ子コマ/カットイン）対応**:
   - 大ゴマの中に小ゴマを浮かせるカットイン演出（Z-Indexによる自動くり抜き差分マスク）に対応。
5. **日本式MANGA読み順（右上始点）の自動ナンバリング**:
   - コマを分割・配置した瞬間に、**右上（コマ1）→ 左上（コマ2）→ 右下（コマ3）…** の順で自動ソート＆カラーバッジを割り当て。
6. **WebUI解像度（Width/Height）リアルタイム連動**:
   - WebUIスライダーで設定した生成解像度のアスペクト比を用紙キャンバスが自動追従。
7. **Single-Pass 爆速生成**:
   - Forgeネイティブな1パス同時空間アテンション制御により、4〜6コマあっても生成速度は通常生成とほぼ同等（約1.2〜1.4倍）。

---

## 📂 インストール・配置手順

### 簡単な導入手順
1. 本フォルダ（`EasyReforgeExtension`）のファイル一式を、EasyReforgeの拡張機能フォルダへ配置します：
   ```
   E:\EasyReforge\stable-diffusion-webui-reForge\extensions\easyreforge-manga-prompter\
   ```
2. EasyReforge（WebUI）を再起動（またはUIの再読み込み）します。
3. WebUI画面の下部に **「🎨 Manga Region Prompter (漫画コマ割りプロンプター)」** というアコーディオンが追加されます。

---

## 📖 使い方ガイド

1. **有効化**:
   - アコーディオンを開き、**「有効化 (Enable)」** にチェックを入れます。
2. **コマ割り**:
   - 「王道テンプレート（4コマ、3コマ、5コマ、カットインなど）」をクリックして選ぶか、
   - キャンバス上で「＋ 横スラッシュ分割」「＋ 縦スラッシュ分割」を押して好みのコマ割りにします。
   - コマ間の水色の境界線をドラッグしてコマの大きさを調整します。
3. **プロンプト入力**:
   - 右側のコマ一覧（カラーバッジ付き）に、それぞれのコマに描きたいプロンプトを入力します。
   - （例: コマ1 `1girl, smiling`, コマ2 `1boy, surprised`）
4. **生成**:
   - あとは通常通り「Generate」を押すだけで、各コマに狙った内容が描かれた1枚の漫画ページが生成されます！

---

## ⌨️ ショートカットキー
- `Ctrl + Z`: 直前の操作を元に戻す (Undo)
- `Ctrl + Y` (または `Ctrl + Shift + Z`): やり直す (Redo)
