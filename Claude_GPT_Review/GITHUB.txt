# TEGAKI — 外部WEB AI向け GitHub読解リンク集

更新日: 2026-09-06
対象: 現行コード・製品思想・技術契約・現在の計画。Archive / 過去Reviewは収録しない。
このリンク集は案内であり、仕様の第二正本ではない。

重要: URLはmainの可変参照。ローカル変更はOwnerがpushするまで外部AIには見えない。
レビュー開始時に対象commitを確認し、必要なら refs/heads/main を対象commit SHAへ置換する。
以下はローカル実在と重複を検証するが、公開先の最新内容との一致は別確認。

読む順序: AGENTS → docs/README → STATUS → TECHNICAL → ARCHITECTURE / VOCABULARY。
製品思想の評価ならPRODUCT、計画の評価ならROADMAPとWork Packageへ進む。
AUDITには調査済み・未確認・既知不具合を分けている。製品実装は再構成レビュー中のため停止中。
実装対象を限定し、全コードやArchiveを最初から読み直す必要はない。
